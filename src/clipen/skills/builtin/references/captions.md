# 字幕

保留原話，使用繁體中文呈現。普通對話不逐字彈跳；真正的重點才強調，情緒來自素材。
字幕要跟得上實際語音：ASR 句段、字數比例估時、forced alignment 是不同證據。
不把長 ASR 視窗平均切給每個字；沒有可靠字詞時間的分頁／摘錄只能當待修草稿。
不可只保留一小句已對齊字幕，刪掉其他字幕後宣稱全片完成。
字幕完整性會逐句檢查保留的原音；摘錄字幕也不能讓仍在播放的其他口語變成沒有字幕。
快剪段落切在半句話時，依 references/editing.md 的「快剪段落的原音」處理：擴成完整句子，或明確靜音交給配樂。
不可藉刪掉所有對話逃避同步修復。先補對齊或保留待修區間，草稿可以預覽，但別宣稱字幕完成。
transcribe_source_range 按需取得來源口語，預設嘗試本機字詞對齊。若缺環境，用 prepare_local_speech
準備 transcription／alignment，再讀工作結果；align_source_speech 可重用既有轉寫文字補對齊。
若上下文或使用者回饋支持辨識錯字，用 revise_source_speech 提出更正與依據並重新對齊；
保留原始 ASR 和模型更正標記，不因更正成功就聲稱已核對真實發言。
底部留給口語字幕；資訊標註移到側邊或上方。不要用標籤覆蓋表情、餐點細節或同時顯示的字幕。
