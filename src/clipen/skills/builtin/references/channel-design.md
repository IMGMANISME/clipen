# 節目包裝：從觀看理由到畫面語彙

先讀 intent.template 的 design_direction、editorial_direction、references，再讀該模板 preview_resource。
預覽與八秒無聲示例都是 Clipen 原創插畫場景；字標、標籤與動態使用正式影片同一個渲染器。
示例的插畫、台詞、人物署名、路線與任務勾選不代表來源事實，不能帶進成片。

## 選定的方向要改變哪些決策

每套樣板的標題、小標、反應字、資訊各有自己的造型與進場方式，不只是換顏色。

| 樣板 | 畫面構成與節奏 | 敘事用途 |
| --- | --- | --- |
| 旅遊 vlog | 手札體描邊標題、膠帶地點小標、黃色貼圖反應字，彈出進場 | 第一人稱：出發 → 路上 → 到了 → 感想 |
| 產品開箱 | 斜切色塊標題、黑底規格標籤、爆炸星形反應字，震動進場 | 包裝 → 內容物 → 第一印象 |
| 旅遊精華 | 寬字距宋體、細線地點、不用貼圖，全部緩慢淡入，2.35:1 黑邊 | 畫面與音樂主導的精選 |
| 美食探店 | 圓體膠囊店名、價格吊牌、對話框反應，彈跳進場 | 為什麼來 → 點了什麼 → 第一口 |
| 日常 vlog | 翩翩體手寫、波浪底線、小閃光，像寫字一樣逐步出現 | 一天裡的小事，像跟朋友聊天 |
| 產品 demo | 深色介面面板、STEP 鍵帽小標、直線指示，從左滑入 | 一步一步的操作 |
| 產品評測 | 螢光筆標題、優點打勾／缺點打叉、印章結論，蓋章進場 | 實測 → 優缺點 → 結論 |
| 活動紀錄 | 楷書金色標題配細線、名字加底線、柔光重點字，典雅淡入 | 流程中的重點時刻與現場氣氛 |
| 短影音精華 | 紅黑雙描邊大字、螢光色塊小標、帶陰影爆字，直式 9:16 | 前 1 秒抓住目光的快節奏精華 |

主標、章節、資訊、重點反應是不同用途，依事件選用，不必每段四種全放。
字標直接疊在有內容的鏡頭上；不同位置讓出人臉、手部操作、食物與店招。
音樂、剪點、字幕都跟著同一種節目節奏，不能只換外框卻保留完全相同的影片結構。
規格、價格、分數要有素材或使用者資料；沒有證據就省略，不填示例數字。
產品評測的資訊以「優點」開頭會顯示打勾，以「缺點」開頭會顯示紅色打叉；不要用這個標記表達講者沒說過的評價。

## 參考來源與轉化邊界

不代表已逐格檢視完整影片，也不推論未公開的製作流程。完整來源亦隨 templates.json 凍結在工作內。
