# 檢視與修改

先渲染草稿再看具體區間，可以缺少未完成的後製，但 UI 和報告必須列出待辦。
檢查字幕起迄、資訊依據、箭頭目標、字體換行、動畫開始與退場，以及聲音的實際組成。
比較上一版：新元件是否讓觀眾更容易理解，還是遮住反應？音效或音樂是否破壞原音？
逐鏡截圖不能證明看完連續動作，量測不能證明聽感。說清已取得與尚缺的證據。
打磨時只需檢視改過的鏡頭與文字：同一工作中已通過、且內容與前後轉場都沒變的鏡頭會被沿用，不必重看。每張截圖都會留在 AI 的上下文裡，重看沒改過的鏡頭只會更快耗盡額度。
有嚴重問題就保留 finding 並修改；不能只換一句評語把它改成通過。
可播放、製作需求完整、AI 自評及使用者接受是不同狀態。交付要附可編輯修訂、Skill 版本與來源授權。

先用 inspect_pacing 找出長段連續來源，再檢查它是否確實推進事件；把同一搖鏡切成多段不算增加內容。
回看「問題／目標 → 實際看到或做到的事 → 本段留下的發現」是否能從來源讀到；元件名稱和工具成功不能代答。
若樣片多半仍是尋路，請探索同事件的後續素材或縮短成真正有內容的一段。
逐句檢查保留口語的字幕覆蓋；對齊失敗應修復或留下未完成狀態，不能刪掉字幕後交付。

長片先按章節檢查，再檢查章節交界的敘事與聲音。約十分鐘工作交付時不能拿一分鐘樣片充數。片長與數量上限依本次凍結的 intent 與 production limits；未指定長片的工作維持樣片範圍。
