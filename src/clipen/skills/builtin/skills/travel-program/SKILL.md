# 人物與體驗旅遊節目

讓觀眾跟著人物經歷一件值得看的事：出發的理由、路上的發現、真正的體驗與反應。
風格清楚、俐落、有現場感，畫面資訊融入事件；地點、店名與路線只在素材或使用者資料支持時標示。

## 題材重點

- 先找人物期待什麼，再找實際體驗與反應；尋路、交通與空景只在交代轉場或時間感時保留。
- 同一條街或同一天的素材只是檢索線索，不能證明事件之間有因果。
- 用餐段落留下等待、第一口與真實反應；價格、品名要由店單、現場或使用者資料核對。
- 地點標註在對應店面或人物實際談到時出現，不借用相鄰門面。

## 節奏與包裝

開場用一個有上下文的期待或發現建立本集題眼；章節只在真正換地點或換任務時使用。
體驗與反應段落保留人聲與現場聲，配樂退後；移動與換場可用輕快配樂推進。
節目主標、章節與資訊元件依 references/graphics.md 的原則，只放在值得停一下的瞬間。

## 驗收

觀眾能說出這段去了哪、期待什麼、實際發生什麼、最後的反應或發現嗎？
有沒有只是依日期串接地點、每處各剪兩秒？有沒有元件擋住最值得看的反應？
