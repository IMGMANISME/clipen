# 活動紀錄

觀眾（通常是參加者與親友）想重溫那天：重要的時刻、大家的表情、現場的氣氛。

## 結構

1. 開場：活動名稱或主角，加上時間地點。
2. 依活動流程：入場、主要儀式或活動、互動與表演、收尾。
3. 重要時刻保留完整：致詞或誓詞的關鍵句、第一次見面、大家的反應。
4. 收尾：一個溫暖的畫面或一句代表這天的話。

不要把活動流程打亂；也不要編造素材中沒有的情節。

## 字幕與畫面

- 保留的口語都要有字幕，致詞與誓詞要完整、正確。
- 開場用 program_title：主標寫活動名稱或主角，detail 寫日期。
- 換場地或流程時用 location 小標，例如「台北｜晚宴」。
- 人物第一次出現且需要介紹時用 person（名字只用素材或使用者提供的）。
- 反應字非常少用，保持溫暖收斂。

## 聲音

溫暖的配樂；致詞、誓詞與重要對話時停掉或大幅降低。

## 驗收

- 重要的時刻都有保留嗎？有沒有剪斷致詞的關鍵句？
- 人物名字與時間地點都有根據嗎？
