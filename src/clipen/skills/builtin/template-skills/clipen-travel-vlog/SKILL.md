# 旅遊 vlog

觀眾是跟著你去旅行的朋友。他們想知道：去哪裡、為什麼去、路上發生什麼、你覺得怎麼樣。

## 結構

1. 開場（前 10 秒）：一句話交代今天要去哪、要做什麼，配一個最有代表性的畫面。不要長時間空景或自我介紹。
2. 出發與移動：只留交代方向或有趣小事的片段；搭車、走路的畫面短短帶過。
3. 到了：每個地點先用一個能看出環境的鏡頭，再接你實際做的事與反應。
4. 收尾：講者自己的感想或一句結論；沒有就用當天最後的畫面安靜結束。

依素材的時間順序剪；跳過的時間用硬切或短暫淡轉，不要每一刀都加轉場。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title 放本集主題，detail 放日期或第幾天（有依據才寫）。
- 第一次到一個地點用 location 標地名；店名、站名只在畫面或講者說出口時標。
- 花費、營業時間、交通方式這類資訊用 fact，必須有來源。
- 真的驚訝或好笑的反應才用 impact 或 reaction，一支片三到五次就夠。
- 換一天或換一個城市時才用 chapter。
- 元件放在不擋臉和主要風景的位置，地點條通常在左下。

## 聲音

保留現場聲和說話聲。配樂用在移動、轉場與空景；有人說話時降低，不要蓋過講者。

## 驗收

- 看完能說出今天去了哪些地方、順序是什麼嗎？
- 每個地點都有「做了什麼」或「覺得怎樣」，而不只是風景嗎？
- 地名、店名、價格都有根據嗎？
