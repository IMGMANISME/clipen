# 產品評測

觀眾想知道：值不值得買、適不適合自己。

## 結構

1. 開場：一句話說評測什麼產品、用了多久，先給一個吸引人的問題（例如「真的值得買嗎？」）。
2. 測了什麼、怎麼測：講者實際做的測試與使用情境。
3. 優點：逐項說明，每項配一個證明的畫面。
4. 缺點：逐項說明，同樣配畫面。
5. 結論：適合誰、不適合誰；講者的最終評價。

所有評價、分數、比較都只能來自素材裡講者說過或展示過的內容。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title，detail 寫一個問題。
- 每個優點或缺點用 fact 標示，例如「優點｜續航很久」「缺點｜有點重」。
- 結論用 headline 大字。
- 講者強烈的反應才用 reaction；impact 整支片最多一次。

## 聲音

配樂穩定低調，說明與比較時降低。

## 驗收

- 看完知道優點、缺點與結論嗎？
- 每個評價都有講者的話或實際畫面支持嗎？
