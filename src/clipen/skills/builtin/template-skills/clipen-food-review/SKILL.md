# 美食探店

觀眾想知道：這家店在哪、為什麼值得來、點了什麼、到底好不好吃。

## 結構

1. 開場：一句話說今天要吃什麼、為什麼來（排隊、口碑、朋友推薦…以素材為準）。
2. 店門口或店內：交代店名與環境，一兩個鏡頭就好。
3. 點餐：點了哪些、價格多少（菜單或講者說出口才標）。
4. 上桌與第一口：餐點特寫、第一口完整保留，接講者真實的反應。
5. 吃完的感想：好吃在哪、會不會再來；沒有就安靜收尾。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title：主標寫店或料理，detail 寫一句副標。
- 店名用 location 放左上角；餐點名稱與價格用 fact，放在食物旁邊。
- 第一口之後，講者真心好吃或驚訝時才用 reaction，一支片兩三次就好。
- 元件不要蓋住食物和講者的嘴。

## 聲音

保留吃東西、上菜的現場聲；配樂輕快，說感想時降低。

## 驗收

- 看完知道店名、點了什麼、價格與感想嗎？
- 價格、店名有根據嗎？有沒有把沒說過的評價加進來？
