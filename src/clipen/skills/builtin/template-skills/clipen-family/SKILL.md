# 家裡有小劇場

圓角對話泡泡、手畫小太陽與生活剪貼，用互動串起一集。

## 套用與工具

本 Skill 與 manifest.json 一起隨製作工作凍結。從 get_edit_status 讀取本次需求、片長、既有時間軸與手動參考；使用者本次指示優先。
使用共用製作 Skill 的來源、版本與權限流程，以現有 MCP 工具執行。本文件的資源路徑均相對於製作套件根目錄，透過 read_production_skill 讀取。
先看 `assets/style-tpl-family.png`，並讀 `visual_styles.json` 與 `font_styles.json` 中選定的設定。
本套畫面風格為 `tpl-family`，預設字體為 `calligraphy`；使用者可另外換字體。
用 list_program_components 選語意元件，透過 add_program_component / update_program_component 編輯；本套 presets 的構圖只是參考；新增時看過該鏡畫面後明確指定 x、y，避開人臉、動作與字幕，不讓每個元件都落在同一角。

## 故事與節奏

從家人之間的一件小事開始，以互動、意外和回應累積日常的小劇場；結尾回扣當天的小目標，不強造戲劇衝突。

讓對話有接續與反應時間，動作和表情相互承接；可以濃縮等待，但不要移接不同語境的反應製造尷尬或矛盾。

## 字幕與後製畫面

人物原話才上字幕；短對話泡泡用於已發生的資訊或反應，不替孩子、寵物或沉默者捏造內心台詞。

圓角泡泡、生活剪貼與小太陽形成識別；program_title 建立今天的小事，person 辨識人物，reaction 點出真實反應。不要每張臉都配一個泡泡。

## 動畫與聲音

柔和跳入與短淡入，跟著互動而非每鏡固定入場；轉場可用同一生活物件銜接，留下人物關係。

溫暖配樂襯底，家人聲音優先；小動作可用輕音效，但不能把一般互動剪成失敗或嘲弄。重要對話時降低配樂。

配樂若由使用者指定就沿用，否則使用音樂工具尋找並保存來源與授權。僅能依量測和證據調整音訊，不能宣稱已實際聆聽。

## 持續修改與驗收

繼續編輯時保留本工作的凍結 Skill，先讀目前修訂與修改要求；只修改受影響範圍，保留手動位置、字幕、音軌與未受影響的剪點。
若需要換風格，依使用者明確要求使用 restyle_program_components；不能默默改成另一套模板或重建整片。

人物關係與事件是否好理解？反應有完整語境嗎？溫暖來自互動，還是只靠柔光和音樂宣告？

用 render_preview 檢查實際版面、字體、動態與剪點，再依本次修訂回看。量測成功不等於美感通過；目前不支援的元件、動畫或音訊感知需保留具體待辦。

## 設計參考

- [Casey Neistat：DO WHAT YOU CAN’T](https://www.youtube.com/watch?v=jG7dSXcfVqE)：手作標記與生活物件承載資訊；參考公開作品與手寫圖像，轉成 Clipen 原創版面。

參考僅用於設計原則，圖形與排版由 Clipen 原創。示例的文字、插畫、數字與反應都不是本次來源證據。
