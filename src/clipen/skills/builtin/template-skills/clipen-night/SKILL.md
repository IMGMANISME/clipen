# 霓虹末班車

冷暖錯位霓虹字、開口框線與城市索引，夜景也有節目識別。

## 套用與工具

本 Skill 與 manifest.json 一起隨製作工作凍結。從 get_edit_status 讀取本次需求、片長、既有時間軸與手動參考；使用者本次指示優先。
使用共用製作 Skill 的來源、版本與權限流程，以現有 MCP 工具執行。本文件的資源路徑均相對於製作套件根目錄，透過 read_production_skill 讀取。
先看 `assets/style-tpl-night.png`，並讀 `visual_styles.json` 與 `font_styles.json` 中選定的設定。
本套畫面風格為 `tpl-night`，預設字體為 `street`；使用者可另外換字體。
用 list_program_components 選語意元件，透過 add_program_component / update_program_component 編輯；本套 presets 的構圖只是參考；新增時看過該鏡畫面後明確指定 x、y，避開人臉、動作與字幕，不讓每個元件都落在同一角。

## 故事與節奏

以入夜後的一個目的地或選擇串聯，保留找路、等待、發現與結果；夜景應推進這次經歷，不是隨機夜景合集。

依光源與移動方向銜接街道、店內和人物；建立地點後再給招牌與細節，別用過度壓暗掩蓋素材問題。

## 字幕與後製畫面

夜色中維持字幕對比，發光招牌附近避免再放霓虹重點字；口語字幕保持易讀，不套用霓虹字描邊到整段台詞。

program_title 用錯位霓虹與開口框線，位置避開路線和招牌；location 建立換場，headline 揭示本段選擇。每段保留一個主要視覺焦點。

## 動畫與聲音

分階段亮起與輕微錯位收攏；銜接可利用進出暗部或動作，但不添加無事件依據的故障閃爍。

低密度電子氛圍承接街道聲，人物對話與店內聲音優先；從熱鬧街頭到安靜場景時讓聲音密度也改變。

配樂若由使用者指定就沿用，否則使用音樂工具尋找並保存來源與授權。僅能依量測和證據調整音訊，不能宣稱已實際聆聽。

## 持續修改與驗收

繼續編輯時保留本工作的凍結 Skill，先讀目前修訂與修改要求；只修改受影響範圍，保留手動位置、字幕、音軌與未受影響的剪點。
若需要換風格，依使用者明確要求使用 restyle_program_components；不能默默改成另一套模板或重建整片。

觀眾知道現在去哪裡、為什麼去嗎？霓虹元件是否與店招爭搶？暗部和字幕在實際預覽中仍可辨識嗎？

用 render_preview 檢查實際版面、字體、動態與剪點，再依本次修訂回看。量測成功不等於美感通過；目前不支援的元件、動畫或音訊感知需保留具體待辦。

## 設計參考

- [Peter McKinnon：THE BUCKET SHOT](https://www.youtube.com/watch?v=r25IWquxe9s)：以明確目標建立旅行影誌、片名留白與景別對比；參考官方作品與公開視覺。
- [MKBHD / Maxwell Hathaway：MKBHD · Main Title Design & Animation](https://www.maxhwy.com/mkbhd)：可延展的頻道包裝、幾何識別與乾淨資訊層次；參考原設計師作品頁。
