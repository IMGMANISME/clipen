# 短影音精華

觀眾在滑手機，第一秒不吸引人就會滑走。

## 結構

1. 第一秒：直接放最好笑、最驚人或最有懸念的瞬間，配一句大字。
2. 接著快速交代來龍去脈：發生什麼、在哪裡。
3. 高潮與結果：最精彩的部分完整保留。
4. 結尾：一句結論或反轉；不需要長收尾。

每 2–3 秒要有新畫面或新資訊。片長 30–60 秒；使用者另有指定時照指定。

## 版面

- 使用直式 9:16 畫布（set_canvas，例如 1080×1920）。
- 主體放在畫面中間；元件與字幕避開上方與下方各約 10% 的區域（平台介面會蓋住）。

## 字幕與畫面

- 每句口語都要有字幕，可以比橫式影片大一些。
- 開場用 headline 或 program_title 放一句抓人的大字，置中。
- 重點詞用 reaction 或 impact 跟著台詞跳出，但同一時間只放一個。
- 地點或資訊用 location、fact，簡短。

## 聲音

節奏明快的配樂，剪點跟著拍子；說話時降低配樂。

## 驗收

- 前 1 秒有沒有抓住目光？
- 30–60 秒內有沒有講完一件事？畫面有沒有被平台介面擋住的元件？
