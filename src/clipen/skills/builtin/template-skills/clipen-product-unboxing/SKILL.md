# 產品開箱

觀眾想知道：這是什麼、盒子裡有什麼、拿在手上的感覺、值不值得注意。開箱影片的重點是看得清楚，不是特效。

## 結構

1. 開場：一句話說這是什麼產品、為什麼開箱；先給一個產品或外盒的清楚畫面。
2. 外盒與包裝：快速帶過，除非講者特別評論包裝。
3. 內容物：依取出順序，每樣配件給一個看得清楚的鏡頭。
4. 本體：外觀、材質、按鍵或接口等細節，用近拍。
5. 第一次使用與第一印象：開機、戴上、試用的畫面與講者的真實反應。
6. 收尾：講者的結論或還想測試的地方。

不要加入素材中沒有的比較或評分；開箱不是評測。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title 放產品名稱，detail 放一句副標（例如「盒子裡有什麼？」）。
- 品名、型號、規格、價格用 fact；只用包裝、畫面上看得到的字、講者說出口或使用者提供的資訊。
- 需要指出細節（接口、按鍵、材質）時用 pointer 或 circle，目標要準確落在該細節上。
- 換到下一個段落（例如從配件到本體）可用 chapter。
- 講者真心驚訝時才用 reaction；impact 整支片最多一兩次。
- 資訊卡放在產品旁邊的空白處，不要蓋住產品本身。

## 聲音

保留拆封、按鍵等有用的現場聲。配樂乾淨、低調，說明時明顯降低。

## 驗收

- 看完知道產品叫什麼、盒子裡有哪些東西嗎？
- 每個標出來的規格與價格都有根據嗎？
- 產品細節有沒有被元件或字幕擋住？
