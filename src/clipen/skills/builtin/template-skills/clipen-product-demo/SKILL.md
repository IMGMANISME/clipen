# 產品 demo

觀眾想學會怎麼用。每一步都要說清楚、看清楚。

## 結構

1. 開場：一句話說這支影片要示範什麼、做完會得到什麼結果。
2. 分步驟示範：每一步先說要做什麼，再給操作的特寫；照素材中的實際順序。
3. 完成：展示做完的結果。
4. 收尾：一兩個小提醒或常見問題（講者有說才放）。

不要跳過講者實際做過的步驟，也不要加入素材中沒有的步驟。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title，detail 寫第一步或副標。
- 每一步開始時用 chapter 小標，例如「STEP 1｜匯入素材」。
- 需要指出按鍵、選單、接口時用 pointer 或 circle，目標必須準確。
- 設定值、型號、快捷鍵用 fact。
- 很少用 reaction；完成時可以用一次。

## 聲音

講解最重要。配樂低調，講解時明顯降低；保留按鍵、操作的現場聲。

## 驗收

- 觀眾能照著影片一步一步做出來嗎？
- 每個箭頭和圈選都指在正確的位置嗎？
