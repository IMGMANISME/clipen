# 旅遊精華

觀眾想在幾分鐘內感受這趟旅程最美、最有記憶點的瞬間。這不是流水帳，是一支跟著音樂走的短片。

## 結構

1. 開場：一個最有代表性的畫面加上標題（目的地與天數），配樂第一個段落進來。
2. 中段：依地點或時間分成幾段，每段只留最好看、最有動作或表情的鏡頭。
3. 高潮：配樂最強的段落放整趟最精彩的瞬間。
4. 收尾：一個安靜的畫面或一句最有感的話。

剪點跟著配樂的拍子；同一個地點不要重複放很像的鏡頭。說話只留一兩句最有感的原話，其餘交給畫面與音樂。

## 字幕與畫面

- 保留的口語都要有字幕。
- 開場用 program_title：主標寫目的地與天數，detail 寫英文或年份。
- 換地點時用 location 標「地名｜英文」，放左上角。
- 少用資訊與反應元件；真的很驚豔的瞬間才用一次 reaction。
- 畫面乾淨，不要讓元件蓋住風景。

## 聲音

配樂主導。保留少量有氣氛的現場聲（浪聲、街頭、笑聲），說話時降低配樂。

## 驗收

- 不看說明，也能感受到這趟去了哪些地方嗎？
- 剪點有沒有跟著音樂？有沒有重複又相似的畫面？
