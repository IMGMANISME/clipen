# 日常 vlog

觀眾是你的朋友，想知道你今天做了什麼、發生什麼有趣的事。

## 結構

1. 開場：一句話說今天要做什麼，或直接從最有趣的一刻開始。
2. 依一天的時間順序：每件事保留做的過程與講者的反應，無聊的等待短短帶過。
3. 收尾：今天的心得或一句輕鬆的結語。

不需要每段都有轉場；換時間或地點時硬切即可。

## 字幕與畫面

- 每句口語都要有字幕。
- 開場用 program_title；需要時 detail 寫日期或一句副標。
- 好笑、失手、意外的瞬間才用 reaction 或 impact；不要每句都加。
- 換到新的地點或活動時，可用 chapter 小標（例如「下午｜咖啡廳」）。
- 元件放在不擋臉的位置。

## 聲音

保留說話聲和生活感的現場聲；配樂溫暖低調，說話時降低。

## 驗收

- 看完知道今天做了哪些事、順序是什麼嗎？
- 有沒有保留講者真實的反應，而不只是畫面串接？
