# 剪輯與節奏

根據說話和行動決定剪點，留住句尾、表情與必要停頓。片長預算不是要求填滿。
B-roll 解釋當下事件；能保留人物原音時別讓每鏡都換一段不連續聲音。先確認工具支援聲畫分離的方式。
硬切是正常選擇。淡轉適合明確時間／場景變化，不逐鏡加特效。片尾淡出不能冒充有意義的段落轉場。
推近、定格、重播應讓短暫細節或反應更清楚；重複使用來源須說明用途。
小修改優先使用 trim_clip、reorder_clips、split_clip，查閱 invalidated；replace_sequence 是重建整段內容的選擇。

## 避免「有字但內容空」

inspect_pacing 會把同來源相接的片段合併計算。把一段街景分成三鏡、加推近或字幕，仍可能是同一段等待；
片段數和效果數不能證明有推進。先檢視連續來源較長的區間，問中途是否有新資訊、行動或反應。
有用途的對話可以長留；無用途的尋路、搖鏡、對焦與重複交代應縮短，不設定一律每幾秒切鏡的配額。

尋找同一事件的素材搭配：人物建立期待、細節交代對象、實際行動、人物回應。
例如用餐素材除了走路到店，也應探索相鄰素材的餐點、拍照、互動或品嚐；有素材依據才連接。
沒有拍到的體驗不捏造。素材只能支持到餐點上桌，就讓段落在那裡完成，不假裝已有評價。
先確認每個段落帶來的新資訊，再依資訊安排遠景／人物／細節，最後選擇大字或標註。
