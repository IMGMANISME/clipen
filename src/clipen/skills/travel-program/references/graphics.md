# 後製元件與視覺語言

本套包含資訊標籤與有視覺份量的節目設計。不要把整片做成「毛片＋字幕＋偶爾小標籤」。
先用 list_program_components 看本次凍結版本的實際能力，再讀元件 preview_resource 看成品。
保留暖黃、薄荷綠、暖白和墨黑的統一識別；大字、框線、色帶使用相同視覺語言。

## 依敘事安排畫面層次

- 開場：program_title 疊在有觀看理由的鏡頭上，建立節目名稱與本集主題。不是停下來放獨立字卡。
- 揭題／關鍵發現：headline 用斜切色帶與逐字進場，提出觀眾接下來想知道的問題。
- 換段：chapter 用橫幅與延伸線帶入新的地點或體驗，讓段落關係可讀。
- 轉折／真實反應：impact 用撞擊重影與強調線；burst 用放射外框。選一種最符合情緒的處理。
- 必要資訊：location／person／fact 介紹地點、人物與品名；pointer／circle 引導觀眾看細節。
- 輕量補充：reaction 點出實際反應，不要每句對話都放大字。

對每段先決定觀看重點與視覺處理。畫面只有小標籤時，回看是否缺少開場識別、段落帶入或重點揭示。
不要只為通過元件數量檢查而加字；同一時刻保留一個主要視覺焦點，讓觀眾看得到人物與現場。
大字只取關鍵短句，detail 補一行脈絡。程式會在有限範圍內調整字級；文字仍過長時必須改寫。

## 證據與版面

作者可以設計節目名稱、章節名與提問；evidence 說明這是編輯標題及其對應事件，不能冒充來源發言。
價格、評分、地名與人物引言必須有來源。反應字不可捏造人物心聲。
位置使用畫布比例；先看實際畫面再擺，主標也必須避開臉部、食物主體與底部字幕。
元件的整體版面會檢查安全範圍與同時碰撞；同時兩個大字互搶視線時錯開時間，不關閉碰撞檢查。
固定目標沒有自動追蹤；目標移走時縮短或分段，不保留指錯物件的箭頭。

## 動態與回看

各家族有不同的進場動態，按影格實際渲染；不是所有元件一律淡入。
依鏡頭長度留閱讀時間，強調字短促、主標和章節稍長；不要切掉進場就離開。
至少檢視進場、中段、退場與字幕同時出現的畫面；碰撞檢查不能代替人物避讓和設計判斷。
音效配合重點入場，保留好的原音、字幕與配樂，不為增加畫面設計而重做聲音。

## 設計密度來自畫面分工

主標負責識別，章節橫幅負責推進，fact／pointer／circle 讓觀眾看懂具體細節，impact／burst 承接真實反應。
同一段只有左上角主標時，先找能支持內容的特寫、人物鏡頭或動作，再決定疊圖位置與時間。
不要把這些角色都交給一行大字，也不要每種元件輪流用一次。讓大字、精剪、原音、配樂共同服務同一事件。
主標的 detail 寫觀眾需要的資訊；不要顯示「從尋路進入店前發現」「現場第一反應」這類剪輯工作註解。
地點標註必須在對應店面／人物實際談到它時出現；同一條街上的其他門面不能借用這個地名。

## 整套換風格

list_program_components 回傳本工作凍結的 visual_styles 與 selected_visual_style_id；每套可讀 preview_resource。
variety 是粗體、斜切色帶與撞擊動畫；editorial（旅誌編輯部）是錯位雙層主標、印刷花章、剪紙貼紙與票券標註；cinema 是宋體、細線框與緩慢淡入。
有使用者選擇時先遵循選擇。未被要求混搭時，讓本片元件維持同一套視覺語言。
restyle_program_components 可一次換全部或指定 element_ids；只換畫面元件，字幕時間、配樂、剪點與文字都保留。
這個工具只處理既有元件；後續新增時用 visual_style_id 明確延續同一風格。
update_program_component 未指定風格會保留該元件原風格。不同字型可能改變寬度，溢出時工具會拒絕整次換風格。
舊工作只有它凍結的樣式；不可假裝能使用未包含在該工作內的新模板。

字型依本機可用字型選擇，未內附第三方字型；無宋體時會使用可用字型。缺字標點會以可用字型補足，無法顯示的字元會明確拒絕，不輸出缺字方框。

旅誌編輯部的主標會在「・」處分行，無分隔時將長標題分成兩行。請用短而有意義的主標（例如「咖啡・餐桌時光」）；實際位置與兩行字高由工具量測，溢出時縮短文字或移位。花章是節目裝飾，不是來源或評價認證。主標先揭示識別標、再依序出現兩行字與底線；不要用更長的持續時間堆滿畫面。票券適合品名與已知資訊；剪紙貼紙只承接片中實際反應或明確編輯觀點，不替人物編造評價。

## 字體搭配獨立於版型

font_styles.json 提供 default（日常沿用模板）、japanese（日系綜藝厚黑）、street（潮流雜誌粗明體／黑體對比）、travel（質感旅遊細明體）。每組分 title、impact、information、detail 角色，請依 list_program_components 回傳的 selected_font_style_id 與預覽資產選擇。這是實際渲染字型，不是只改介面 CSS。
使用者的字體選擇優先；不要因更換畫面風格而重設它。add_program_component / update_program_component 可用 font_style_id；未指定的更新保留既有字體。restyle_program_components 可搭配現有 visual_style_id 與指定 font_style_id，只換畫面元件的字體組合；保留字幕、音樂與剪點。新增元件時明確延續所選字體。
更換字體可能改變寬度，工具會重新量測並拒絕溢出版面，仍須渲染回看。字型來源為本機安裝的 Hiragino、Heiti、Songti，其他平台按可用 Noto／系統字型替代；不綁定機器絕對路徑；前三種系統字體組合依本機字型替代。缺字以可用字型補足，無法顯示時明確報錯。不得假裝每個平台都會輸出完全相同字形。

handwriting（自然手寫）使用作者原版辰宇落雁體 1.0 等寬版；calligraphy（筆意楷書）使用芫荽。這兩套內附原始 OFL 字型，不需要安裝到系統，主標／重點字保留自然筆畫與細描邊，資訊／補充文字維持易讀黑體。適合旅誌主標、章節與少量重點，長段字幕不改成書寫字。芫荽是楷書筆意，不將它宣稱為草書。
來源版本、雜湊見 font_sources.json，授權全文見 references/font-chenyu-OFL.txt 與 references/font-iansui-OFL.txt。執行時按凍結的 SHA-256 驗證，缺檔或校驗失敗直接報錯，不能靜默換成黑體後仍宣稱用了手寫字。缺字仍依實際字形覆蓋做回看；若混字影響風格，改用其他字型或同義短標。
