# 後製元件與視覺語言

從 list_program_components 取得本版本可渲染的元件。深色窄底、暖白字、黃色重點和克制的進退形成固定識別。
畫面資訊跟著事件出現：餐點登場可補品名；人物指出細節時用 pointer／circle；真正的反應可用 reaction。
location／person 用於必要的首次介紹，不重複貼在每一鏡。reaction 不是代替普通對話的第二套字幕。
標註引用來源，價格、評分、地名有依據才寫。旁白式評論不可冒充人物原話或心聲。
元件 text 是主標，detail 可放有依據的價格、區域或角色補充；由元件呈現資訊層級，避免把整句話擠成一行。
位置與目標使用畫布比例；先看該區間畫面再擺。工具會檢查安全範圍和同時元件碰撞，人臉避讓仍需看畫面。
固定目標不代表自動追蹤：目標移走時縮短元件時間、改位置或分段，不保留指錯物件的箭頭。
觀眾需要注意什麼決定元件，避免畫面一直塞滿。沒有資訊或情緒用途時可以留白。
