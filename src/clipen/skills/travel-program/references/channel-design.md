# 節目包裝：從觀看理由到畫面語彙

先讀 intent.template 的 design_direction、editorial_direction、references，再讀該模板 preview_resource。
預覽與八秒無聲示例都是 Clipen 原創插畫場景；字標、標籤與動態使用正式影片同一個渲染器。
示例的插畫、台詞、人物署名、路線與任務勾選不代表來源事實，不能帶進成片。

## 選定的方向要改變哪些決策

| 模板 | 畫面構成與節奏 | 敘事用途 |
| --- | --- | --- |
| 落雁手作日記 | 筆記側軸、線圈孔、手寫劃線，逐行帶入 | 當下觀察、人物與一天的時間感 |
| 城市解剖室 | 印刷欄線、雙行主標、編輯色塊，分段揭示 | 問題 → 細節 → 有證據的解釋 |
| 慢走電影誌 | 低位細明體、單根細線、緩進與開放留白 | 動作、空間與現場聲，主標短暫出現 |
| 霓虹末班車 | 錯位霓虹字、開口框線、階段亮起 | 夜晚目的地與人物選擇 |
| 今天吃哪邊 | 菜單花章、粗字反應、兩方品名識別 | 選擇 → 體驗 → 有依據的比較回扣 |
| 任務不可能嗎 | 黑黃切角板、警示斜線、有力進場 | 規則 → 嘗試 → 轉折 → 結果 |
| 日常研究所 | 活版菜單、收據邊、細明體與細線 | 日常問題、實作步驟與細小差異 |
| 家裡有小劇場 | 圓角對話泡泡、生活剪貼、柔和入場 | 自然互動與小事件，保留完整語境 |
| 出走座標 | 等高線銘牌、測繪側軸、路徑節點 | 出發動機與路程推進；裝飾不當真實地圖 |
| 人物側寫 | 偏置引號、訪談署名與安靜構圖 | 原話引入人物，行動補充性格 |
| 下一站放映室 | 打孔車票、雙框印刷、票根擦入 | 真實移動與場景切換 |
| 拆開來實測 | 深色規格介面、幾何節點、模組揭示 | 情境 → 操作 → 證據 → 結論 |

主標、章節、資訊、重點反應是不同用途，依事件選用，不必每段四種全放。
字標直接疊在有內容的鏡頭上；不同位置讓出人臉、手部操作、食物與店招。
音樂、剪點、字幕都跟著同一種節目節奏，不能只換外框卻保留完全相同的影片結構。
路線、規格、價格、倒數與分數要有素材或使用者資料；沒有證據就省略，不填示例數字。

## 參考來源與轉化邊界

以下連結於 2026-10-22 查閱。根據公開作品頁、節目介紹、封面與設計師作品整理原則，
不代表已逐格檢視完整影片，也不推論未公開的製作流程。完整來源亦隨 templates.json 凍結在工作內。

- [Joeman：Joe是要對決 S2 雨傘實測](https://hamivideo.hinet.net/product/146824.do?cs=2)：發行頁呈現兩方比較、價差與測試問題。轉成原創菜單花章、雙方識別與任務告示，不使用節目 Logo。
- [MKBHD 頻道包裝／Maxwell Hathaway](https://www.maxhwy.com/mkbhd)：原設計師說明可延展的主標、視覺、動畫與聲音設計。轉成 Clipen 的規格介面與幾何節點，不重製品牌字樣。
- [Vox Video](https://www.vox.com/videos)：官方影片以問題與解釋組織題目。轉成印刷欄線、證據標註與段落揭示，不搬用圖表數據。
- [Johnny Harris：How I Make My Maps](https://www.youtube.com/watch?v=GsojLuJpe_0)／[創作者官方作品頁](https://www.johnnyharris.ch/)：地圖作為敘事工具。轉成路程節點與測繪圖形；目前靜態指示元件不等於自動地理地圖或物件追蹤。
- [Peter McKinnon：THE BUCKET SHOT](https://www.youtube.com/watch?v=r25IWquxe9s)：以明確目標建立旅行影誌的參考。轉成短片名字標、留白及人物與環境交錯，仍需從本次素材找主線。
- [Casey Neistat：DO WHAT YOU CAN’T](https://www.youtube.com/watch?v=jG7dSXcfVqE)：手作標記與生活物件作為視覺靈感。轉成筆記頁邊與生活剪貼，不搬用創作者口號。
- [James Hoffmann：How To Make The Best Coffee At Home](https://www.youtube.com/watch?v=X9tg3J5OiYU)：以日常問題與實作細節切入。轉成菜單層級與收據標註，不假造本次來源沒有呈現的步驟。
