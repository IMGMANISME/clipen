# 出走座標

等高線、測繪側軸與深綠探險銘牌，路程本身就是故事。

## 套用與工具

本 Skill 與 manifest.json 一起隨製作工作凍結。從 get_edit_status 讀取本次需求、片長、既有時間軸與手動參考；使用者本次指示優先。
使用共用製作 Skill 的來源、版本與權限流程，以現有 MCP 工具執行。本文件的資源路徑均相對於製作套件根目錄，透過 read_production_skill 讀取。
先看 `assets/style-tpl-outdoor.png`，並讀 `visual_styles.json` 與 `font_styles.json` 中選定的設定。
本套畫面風格為 `tpl-outdoor`，預設字體為 `japanese`；使用者可另外換字體。
用 list_program_components 選語意元件，透過 add_program_component / update_program_component 編輯；預設構圖來自本套 presets，仍須避開人臉、動作與字幕。

## 故事與節奏

交代為何出發、路上遇到什麼與抵達的意義；路程的難易與結果必須來自素材，不把風景剪成冒險證據。

以行進方向與路況銜接遠景、腳步與人物狀態；必要時保留停下、確認和折返，讓行程有實際進展。

## 字幕與後製畫面

提醒與對話清楚易讀；地名、海拔、距離、時間等須核對，不用字幕自行補足未知資訊。

等高線銘牌與測繪側軸建立探險識別，location/chapter 交代實際節點，pointer 指向路況。裝飾等高線不是地圖，未支援的路徑動畫不能假稱已完成。

## 動畫與聲音

用節點揭示與平穩線條呼應路程，少量主標避免擋住路面；轉場優先跟著步伐與方向。

保留風、腳步、呼吸與必要提醒，器樂依路程改變密度；原音過響時降低對應片段，不壓掉重要安全訊息。

配樂若由使用者指定就沿用，否則使用音樂工具尋找並保存來源與授權。僅能依量測和證據調整音訊，不能宣稱已實際聆聽。

## 持續修改與驗收

繼續編輯時保留本工作的凍結 Skill，先讀目前修訂與修改要求；只修改受影響範圍，保留手動位置、字幕、音軌與未受影響的剪點。
若需要換風格，依使用者明確要求使用 restyle_program_components；不能默默改成另一套模板或重建整片。

路程順序和人物狀態可信嗎？裝飾圖形是否容易被誤認為精確地圖？抵達段是否回應出發動機？

用 render_preview 檢查實際版面、字體、動態與剪點，再依本次修訂回看。量測成功不等於美感通過；目前不支援的元件、動畫或音訊感知需保留具體待辦。

## 設計參考

- [Johnny Harris：How I Make My Maps](https://www.youtube.com/watch?v=GsojLuJpe_0)：地圖、路徑與局部細節協助敘事；參考創作者製作教學與官方作品頁。
- [Peter McKinnon：THE BUCKET SHOT](https://www.youtube.com/watch?v=r25IWquxe9s)：以明確目標建立旅行影誌、片名留白與景別對比；參考官方作品與公開視覺。
