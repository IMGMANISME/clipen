# 落雁手作日記

筆記頁邊、線圈孔、手寫劃線，像剪進影片的一頁旅行手帳。

## 套用與工具

本 Skill 與 manifest.json 一起隨製作工作凍結。從 get_edit_status 讀取本次需求、片長、既有時間軸與手動參考；使用者本次指示優先。
使用共用製作 Skill 的來源、版本與權限流程，以現有 MCP 工具執行。本文件的資源路徑均相對於製作套件根目錄，透過 read_production_skill 讀取。
先看 `assets/style-tpl-journal.png`，並讀 `visual_styles.json` 與 `font_styles.json` 中選定的設定。
本套畫面風格為 `tpl-journal`，預設字體為 `handwriting`；使用者可另外換字體。
用 list_program_components 選語意元件，透過 add_program_component / update_program_component 編輯；預設構圖來自本套 presets，仍須避開人臉、動作與字幕。

## 故事與節奏

從一個當天的小願望開始，讓觀察、人物互動與途中改變累積成一頁日記；收尾回到最初的心情或物件。不要用景點清單替代經歷。

用完整動作與視線銜接帶觀眾前進，移動段落可用物件、腳步和街角做省略；人物有反應時先留住反應，再帶入下一個地方。

## 字幕與後製畫面

口語字幕跟隨已核對的發聲時間；感想留在手寫邊註，一般台詞用易讀黑體。落雁體用於短主標與有依據的重點字，不將長段對話寫成手帳。

program_title 用筆記側軸與逐行手寫；fact/location 像頁邊註記，pointer 指向實際細節。畫面已有文字時減少邊註，避免把旅誌變成票券拼貼。

## 動畫與聲音

使用筆觸展開、逐行淡入，場景銜接優先跟著動作；不為每次換鏡加入彈跳或撞擊。

以溫暖器樂襯底，抵達、說話與小聲反應讓原音靠前；轉場可保留一小段上一場現場聲。

配樂若由使用者指定就沿用，否則使用音樂工具尋找並保存來源與授權。僅能依量測和證據調整音訊，不能宣稱已實際聆聽。

## 持續修改與驗收

繼續編輯時保留本工作的凍結 Skill，先讀目前修訂與修改要求；只修改受影響範圍，保留手動位置、字幕、音軌與未受影響的剪點。
若需要換風格，依使用者明確要求使用 restyle_program_components；不能默默改成另一套模板或重建整片。

開場願望和收尾是否有回扣？人物和細節是否連成一天？手寫註記是否讓觀眾知道更多，而不是重複字幕？

用 render_preview 檢查實際版面、字體、動態與剪點，再依本次修訂回看。量測成功不等於美感通過；目前不支援的元件、動畫或音訊感知需保留具體待辦。

## 設計參考

- [Casey Neistat：DO WHAT YOU CAN’T](https://www.youtube.com/watch?v=jG7dSXcfVqE)：手作標記與生活物件承載資訊；參考公開作品與手寫圖像，轉成 Clipen 原創版面。
