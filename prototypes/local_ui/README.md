# 使用說明

[← 回到 Clipen](../../README.md)

目前可啟動本機工作台，查看連線狀態與文字工作紀錄。
素材分析、剪輯計畫、自動剪輯與影片匯出尚未提供；開啟介面不代表 AI 已開始處理工作。

## 使用前準備

- 使用 macOS 或 Linux，並以桌面瀏覽器操作；目前不支援 Windows。
- 已安裝並登入 Codex，且版本支援讀取專案設定。
- 已安裝 Python 3.10 以上，terminal 能以 `python3` 執行。
- 已安裝支援 Ed25519 的 OpenSSL。macOS 內建的 LibreSSL 未必符合要求，需讓
  terminal 使用相容的 OpenSSL。

不需要另外安裝 Python 套件。缺少必要環境時，Clipen 會停止啟動並顯示錯誤，
不會代為安裝軟體或略過檢查。

## 開啟工作台

下載專案後，在 terminal 進入專案根目錄，再啟動 Codex：

```sh
cd clipen
codex
```

依 AI 工具提示完成登入、專案信任與必要授權。連線成功後會嘗試開啟本機工作台，
並在 terminal 提供可重開的完整連結。無須另外啟動 Clipen 服務。

若沒有自動開頁，可點開 terminal 的連結。部分 AI 工具的全畫面介面可能覆蓋
連結提示；沒有控制終端的執行環境也可能無法顯示它。

同一份專案請只開一個 AI 工作台；若已有服務在使用，先結束原本的 AI terminal。

### 其他 AI 入口

專案也附有 Claude Code 的連線設定，可在專案根目錄改用 `claude` 啟動，
首次使用需自行批准專案與連線權限。此入口的完整啟動相容性尚未確認，
目前建議先使用 Codex。Gemini 與本機 LLM 入口尚未提供。

## 關閉與重新開啟

| 你的操作 | 工作台的行為 |
| --- | --- |
| 只關閉瀏覽器分頁 | 服務繼續執行，可用 terminal 的同一個完整連結重開。 |
| 關閉 AI terminal | 服務停止，舊連結失效；已開分頁會在偵測斷線後停用。 |
| 再次啟動 AI | 使用新連結進入；已保存的紀錄仍在，未完成工作需先核對。 |

未送出的草稿只留在目前分頁。工作台斷線後可以複製保存，但關閉分頁或瀏覽器後
不保證能還原。不要因為不確定是否送出，就直接建立另一筆相同工作。

## 常見問題

### 連線成功，為什麼不能送出？

目前尚不能從 UI 自動喚醒 AI。只有 AI 正在等待接件、文字有效且你已確認
送出授權時，送出按鈕才會啟用。僅開啟介面不會開始 AI 工作，也不會開始剪片。

### 本機連結為什麼每次不同？

工作台使用 `127.0.0.1`，也就是這台電腦本身；每次啟動可能使用不同連接埠。
完整連結包含本次操作權限，只在服務執行期間有效，不適合分享或放進問題回報。
請使用 terminal 顯示的完整連結，而不是登入後瀏覽器列中簡化的網址。

### AI 停止後，重新檢查連線會再送出工作嗎？

不會。重新檢查只確認原服務是否仍在；若服務已結束，請重新啟動 AI 並使用
新的連結。已保存但未完成的工作需要先核對，再決定是否重送。

### 資料是否都留在本機？

介面與工作紀錄在本機；使用雲端 AI 時，你授權送出的文字仍會交給該服務處理。
請不要送出私人或敏感資料。模型的權限與費用依所選 AI 服務而定，停止工作台收件
不保證已開始的模型運算或計費也隨即停止。

## 回報問題

請在 [Issues](https://github.com/IMGMANISME/clipen/issues) 描述操作步驟、預期結果
與實際情況，並提供作業系統及 AI 工具版本。請勿附上完整工作台連結、憑證、
私人素材、逐字稿或完整 AI 對話。
